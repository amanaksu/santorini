# 산토리니 (Santorini)

아이패드용 산토리니 보드게임 웹앱입니다. 설치 없이 GitHub Pages 링크로 접속해서 플레이합니다.

## 기능
- 2인 플레이(한 기기에서 번갈아 플레이) / AI 쉬움 / AI 보통
- 이동 가능한 칸(초록), 건설 가능한 칸(노랑) 자동 표시
- 되돌리기, 규칙 보기
- 진행 중인 게임 자동 저장 (새로고침해도 이어서)
- 가로/세로 화면 모두 지원

## GitHub Pages로 올리기
1. GitHub에서 새 저장소를 만듭니다 (예: `santorini`, **Public**).
2. `index.html`, `icon.png`, `README.md`를 업로드합니다  
   (저장소 화면 → **Add file → Upload files** → 끌어다 놓기 → **Commit changes**).
3. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main** / **(root)** → **Save**.
4. 1~2분 뒤 `https://<깃허브아이디>.github.io/santorini/` 로 접속합니다.

## 아이패드에서 앱처럼 쓰기
Safari로 위 링크 접속 → 공유 버튼 → **홈 화면에 추가**.  
홈 화면 아이콘으로 열면 주소창 없이 전체 화면으로 실행됩니다.

## 규칙 요약
- 각자 일꾼 2개를 놓고 시작합니다.
- 내 차례: 일꾼 하나를 **이동**(주변 8칸, 오르막은 1층까지)한 뒤, 그 주변에 **건설**합니다.
- 3층 위에는 돔이 올라가 아무도 올라갈 수 없습니다.
- 일꾼이 **3층에 올라서면 승리**, 내 차례에 움직일 수 없으면 패배합니다.
